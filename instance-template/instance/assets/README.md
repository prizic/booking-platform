# Brand assets

Provisioning replaces this file with optimized public PNG brand assets referenced
by `brand.json`. Tenant-authored SVG and every non-PNG format are forbidden.
Files must be regular files (never symlinks), stay within the documented byte and
dimension limits, and pass PNG chunk, checksum, decompression, and pixel-row
validation. EXIF, text, and other metadata chunks are rejected. Customer data
and credentials are forbidden here.
